# Security Policy

## Supported versions

Only the latest `main` userscript is supported.

## Reporting a vulnerability

Do **not** open a public issue for security problems.

Email the maintainer via the address on [github.com/lurui1997](https://github.com/lurui1997), and include:

- A description of the issue
- Steps to reproduce
- Impact (for example: data leak, script injection)

This script only reads WeRead APIs in your logged-in browser session. It does not upload accounts. Please report anything that would change that.
