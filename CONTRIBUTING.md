# Contributing

Thanks for helping improve WeRead Progress.

## Report a bug

Use [Bug report](https://github.com/lurui1997/weread-progress/issues/new?template=bug.yml). Include browser version, Tampermonkey version, script version, and the shelf / book-list URL.

## Suggest a feature

Use [Feature request](https://github.com/lurui1997/weread-progress/issues/new?template=feature.yml).

## Pull requests

1. Fork and create a branch from `main`
2. Keep the change small and focused
3. Run `npm test`
4. Open a PR against `main` and fill in the template

Progress label rules live in `src/label.js` and must stay aligned with [WeRead book.md](https://github.com/Tencent/WeChatReading/blob/main/skills/book.md): `progress === 1` means 1%, not finished.
